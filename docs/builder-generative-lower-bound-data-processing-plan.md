# Finite decoder cells and the Fano frontier

`.local/GenerativeLowerBoundFiniteDataProcessing.lean` stages a finite log-sum inequality for a decoder cell, allowing the cell to be empty. It uses strictly positive input masses within a nonempty cell, as supplied by the full-support finite product laws. The empty cell has both masses zero and contributes zero using Lean's totalized logarithm. The staged export compiles and its transitive axioms are `propext`, `Classical.choice`, and `Quot.sound`; independent review remains pending. Source SHA-256: `e3bb694b8e8ff97049660a7fc6bacafac83a5053e9d5c4bc544237493426aac9`.

For actual measures, the next step is to identify each output atom of a finite decoder pushforward with the sum of input atom masses in its fiber. Apply the cell lemma to every fiber and sum over output atoms. An empty fiber contributes zero; no independence of decoder output and observations is used. To express the result as actual KL, establish the finite-sum formula under absolute continuity, treating an output atom with zero reference mass separately: absolute continuity forces the corresponding source mass to vanish. Finiteness of both KL divergences must be established before `toReal` is used. This gives an oriented KL data-processing inequality for full-support finite input laws and arbitrary finite decoders.

This is a bounded prerequisite only. It does not prove the finite-mixture entropy estimate, Fano inequality, average-testing lower bound, or the source lower-bound theorem; exact K and log 2 constants remain to be derived. In particular, no statistical conclusion is assumed here.
