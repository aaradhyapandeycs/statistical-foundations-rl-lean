`DecisionStage.stepDistribution` is the actual joint distribution π(a|s)P(t|s,a), converted to a Mathlib `PMF` with the real probability mass unchanged. In discrete measurable spaces, `DiscountedMDP.infiniteTrajectoryLaw` uses Mathlib's Ionescu–Tulcea `Kernel.trajMeasure` with this first-step distribution and `historyKernel` applied to the last observed state. The sequence's entries are `(a₀,s₁), (a₁,s₂), …`, with the given initial state s₀ as a separate argument. The law has a proved `IsProbabilityMeasure` instance. `stepMeasure_singleton` identifies the actual mass of each pair, and `historyKernel_apply` exposes the source kernel at every history.

`infiniteTrajectoryLaw_history_step` proves the all-time joint law of each observed prefix and next pair is exactly the prefix law composed with the actual next-step kernel. `infiniteTrajectoryLaw_prefix` identifies every finite prefix of the infinite measure with Mathlib's finite iterated history-kernel `partialTraj` law started from the actual first-step distribution. `infiniteTrajectoryLaw_first` identifies the initial pair law, and `infiniteTrajectoryLaw_one_prefix` proves equality of the first prefix with the separately defined `DecisionStage.trajectoryLaw` after conversion to a probability measure.

**Open boundary:** The all-length equality between the prefix measure and this project's `DecisionStage.trajectoryLaw (List.replicate n ...)` remains unproved. In particular, `infiniteTrajectoryLaw_prefix` is equality to Mathlib's `partialTraj`, not to the project finite path measure; the recursive finite-history representation and the nested `FinitePath` representation still need a measure-preserving conversion and an induction proving their masses agree. The infinite discounted return, its measurability and integrability, and equality of its integral with the finite-return limit / `valueFixedPoint` are also not defined or proved. The Q-conditioned infinite law is likewise outstanding. This file therefore establishes an actual normalized infinite controlled law and partial prefix correspondence, not the source's complete infinite value theorem.
