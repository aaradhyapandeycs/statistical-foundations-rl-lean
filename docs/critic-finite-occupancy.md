## Source reconstruction

For finite state and action sets, horizon H, a nonstationary Markov randomized policy, fixed initial distribution ρ, and the source's transition kernels, first sample s₁ from ρ; for t = 1,…,H sample aₜ from πₜ(·|sₜ), then sₜ₊₁ from Pₜ(·|sₜ,aₜ). For every 1 ≤ h ≤ H, every state and action, dₕ(s;ρ) is the probability of sₕ = s and dₕ(s,a;ρ) is the joint event probability, equal to dₕ(s;ρ)πₕ(a|s). At h=1 the state law is ρ. The source also specializes the same event to one optimal deterministic policy, giving dₕ⋆(s,a) = dₕ⋆(s)·1[a=πₕ⋆(s)]. These are probabilities under the generated law; there is no division by a state probability and no positivity hypothesis for individual events. Rewards and their bounds are source model fields but do not affect these occupancy events.

## Findings

1. `stateAfter` (lines 23–27) starts with ρ and successively binds the actual stage policy and transition; the `FiniteDistribution` codomain proves nonnegativity and normalization. The independent `trajectoryLaw` uses the same policy-transition product. The theorem `stateAfter_expectation_eq_trajectory` (36–49) proves equality to the final-state marginal of that separately constructed law for every bounded finite-carrier test function, with no extra mathematical hypotheses. The state event theorem (66–77) instantiates this with an indicator.
2. `stateActionOccupancy` (58–62) uses the actual one-stage path from the prefix state, including a next-state draw whose probabilities normalize. The joint-event theorem (81–90) expands the prefix as an actual sampled path, then draws the current action and transition. `stateActionOccupancy_eq` (114–121) derives, rather than assumes, the source product for every state and action, including zero-probability states and actions.
3. The `Fin stages.length` index represents exactly h=1,…,H with i=h−1. A nonempty list is necessary to state h=1 or h=H; empty horizon has no decision indices, not a fabricated default. `stateOccupancy_first` (93–96) proves the source initial identity. The general product theorem applies at the final index `tail.length` of `stage :: tail`; independent Lean probes confirmed both boundaries. No reward, transition or policy homogeneity is assumed.
4. **Full-law bridge remains unexported.** The named event theorems use a prefix trajectory, followed for the joint event by a one-stage trajectory. These are the correct generated finite-dimensional laws by inspection, but the file does not prove equality to an event measured directly under `trajectoryLaw stages` over the entire episode. Such a theorem should explicitly marginalize the remaining suffix and identify the path's h-th state and action. The current claims should be described as prefix/current-step trajectory event equivalence until that bridge is proved.
5. **Optimal specialization remains unexported.** The generic factorization is proved, but the file has no theorem connecting the independently constructed optimal greedy stage sequence to the source's indicator formula `eq:dhstar-finite`. The source-specific optimal occupancy claim remains an integration obligation; it should not be marked complete merely from the existence of the generic product theorem.

For `stateActionOccupancy_eq`, the implicit State and Action carriers and Fintype instances are typing/source finite-carrier inputs; `stages` supplies the source's per-stage policy, transition distributions, reward and reward bounds; `ρ` is the source initial distribution; `i` restricts to source decision times; `s` and `a` are arbitrary source values. None is an extra proof obligation or positivity assumption. The event and initial-law theorems use the same inputs, restricted appropriately.
