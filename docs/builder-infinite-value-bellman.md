For any valid source discount in `[0,1)`, `infiniteDiscountedReturn_first_step` proves pathwise that the actual series is `r(s,a₀) + γ·return(s₁, tail(path))`. `infiniteTrajectory_initial_reward` derives the integral of the first reward from the actual first-pair probability law, yielding the policy-weighted reward. The shifted continuation is proved measurable and integrable under the original infinite law. `trajectoryExpectedValue_first_step` combines these facts into an expectation identity with the continuation still integrated over the original actual trajectory law. This is a meaningful first-step equation for arbitrary discount, but it is not yet the source Bellman equation.

For the explicit source-allowed special case γ=0, `trajectoryExpectedValue_bellman_of_discount_zero` proves the actual infinite-path expectation satisfies the state Bellman equation and `trajectoryExpectedValue_eq_valueFixedPoint_of_discount_zero` identifies that expectation with the already-proved unique Bellman fixed point. The extra equality `γ=0` is an explicit specialization, not a hypothesis on the full source theorem or an asserted general solution.

**General Bellman gap:** establish, for arbitrary valid γ, that the integral of `return(s₁, tail(path))` under the original path law equals the policy-transition expectation of `trajectoryExpectedValue π` at the next state. This requires proving the conditional shifted-tail law (or, alternatively, deriving and using the independently developing all-length project finite-trajectory prefix equivalence). Neither the Markov/shift fact, the desired Bellman equation, nor an arbitrary-prefix law is assumed as a hypothesis here. Consequently the full γ>0 state Bellman equation and general identity with `valueFixedPoint` remain open. Infinite Q-value Bellman semantics remain separate.
