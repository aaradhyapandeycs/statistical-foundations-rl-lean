## Source reconstruction and a source discrepancy

The source selects γ∈[2/3,1), 0<ε<1/(32(1−γ)), p=(4γ−1)/(3γ), α=32(1−γ)²ε/(9γ²), and q=p+α. Its policy-hard family has an active state rewarding 1, a zero-reward absorbing state, and an action with stay probability q rather than the baseline p. From the Bellman equation, the active-state optimal value is `G=1/(1−γq)`. Starting with a bad action and then continuing optimally has value **`1+γpG`**, while continuously choosing the bad action has active-state value `B=1/(1−γp)`. These are different Q quantities. The source's displayed formula in lines 1980–1984 substitutes B for the optimal Q of a bad *first* action and its lines 2072–2077 assert the resulting optimal-Q action gap exceeds 2ε. That formula and this claimed source gap do not follow from the defined Q semantics; the implementation uses the correct first-action Bellman expression.

A concrete source-range witness is γ=2/3, ε=1/100, p=5/6 and α=2/225, hence q=379/450. The optimal Bellman fixed-point value at the good action is 675/296, while its value at the bad first action is 671/296. The action gap is therefore 1/74, strictly **less** than 2ε=1/50. These exact rational identities were independently checked against the staged Lean `optimalityFixedPoint` model. The printed Q* formula would give the different value 9/4 at the bad first action. The source's own Bellman optimality characterization implies the above solution is the correct optimal Q; the staged file itself identifies its candidate with the optimality Bellman fixed point, and does not independently establish full trajectory-optimal semantics of that fixed point.

By contrast, under the stationary bad policy, starting with the good action and then following the bad policy incurs a real policy-Q loss `γq(G−B)`. At the same rational parameters it is 379/22200>1/100. The builder proves this different >ε policy-loss statement from the source parameter range; it must not be relabeled as the printed >2ε optimal-action gap.

## Code and scope

1. `bernoulliRow` and `hardMDP` construct actual normalized finite distributions: `true` yields reward 1 and stays with probability q at the designated good action or p otherwise, while `false` has reward 0 and remains false. Discount and reward fields satisfy the project MDP assumptions. The source's absorbing state has only action a₀, whereas this two-state fixed-carrier model makes every Action available there with identical absorbing dynamics and zero reward. This extension preserves the displayed active-state value calculations but adds behaviorally equivalent absorbing-state policy choices; it is not an exact encoding of the entire state-dependent-action family or a uniqueness result for policies there.
2. `hardQ_fixed` checks the candidate against the actual `qOptimality` operator, and uniqueness yields `optimalityFixedPoint_eq_hardQ`. In particular, the good first action has value G and the bad first action has `1+γpG`; the latter is not B. The source's actual trajectory-Q* identification is a separate obligation and is not asserted by this staged file.
3. `sourceHardParameters_valid` constructs valid model probabilities under the source's exact γ and ε ranges without assuming probability validity separately. `sourceAlpha_relation` proves the two algebraic forms of α agree. `sourceHardValue_gap_gt_two` proves `G−B>2ε`; its compared values are the good and bad **stationary-policy state values**, not `Q*(good)−Q*(bad)`. The file does not separately export all source lemma properties such as `1−p≥2α` or the KL upper bound.
4. `badPolicyQ_fixed` checks the actual fixed-policy Q operator for the deterministic bad policy. `hardPolicy_loss_good` gives the exact first-good-action policy loss and `sourceHardPolicy_loss_gt` proves that loss >ε for every source-range γ and ε and any two distinct actions. Its distinct-action hypothesis is needed to instantiate this two-action subcase; this is not an all-estimator statistical lower bound. It assumes neither the desired loss nor probability validity in the source-specialized theorem.
