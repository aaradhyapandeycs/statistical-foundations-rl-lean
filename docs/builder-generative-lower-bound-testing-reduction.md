# Two-point testing-to-estimation reduction

Staged source `.local/GenerativeLowerBoundTestingReduction.lean`, SHA-256 `f145eeb46039c717006cb81a604aa39d75bb76e627db0ccc682fe2fde1b2d255`. Source chapter lines 1791–1835 applies a binary-test lower bound to a 2ε-separated pair of hard MDP values.

For any finite sample space Ω with two actual probability measures μ₀,μ₁ and any real estimator, the midpoint test deterministically maps observations to Bool. If v₁−v₀>2ε, its mistake under either hypothesis implies the corresponding strict estimation error `ε<|estimate−vᵢ|`. The proof accounts for the midpoint tie (assigned to hypothesis 1). Measure monotonicity then proves each actual testing-error probability ≤ its associated actual estimation-error probability. Finally, if **every** binary test has max error strictly above a threshold c, `strict_test_lower_bound_implies_estimation_lower_bound` concludes that at least one of the two estimation-error probabilities is strictly above c. Thus specializing c=0.1 preserves the strict source target; a merely non-strict ≥0.1 premise cannot establish >0.1. No independence between estimator/test and data is assumed. The theorem's universal test premise ranges over all functions; the actual finite sample spaces use discrete measurable structures, so all tests are measurable there.
