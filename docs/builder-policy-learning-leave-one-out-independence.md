# Fixed-parameter leave-one-out independence

Source: `source/upstream/tex/chapters/generative_model_model_based.tex:1203–1219, 1267–1275, 1280–1290`, particularly the fixed-parameter independence statement in the paragraph following `eqn:reward-M-su-inf`; source SHA-256 `b7e7abfb2c2cb2c0dd82470db5ecac3a67d7163682246d499935d9130214ac4d`.

`.local/PolicyLearningLeaveOneOutIndependence.lean` proves the following for the actual policy-learning product sampling law, fixed state `x`, fixed action `a`, and fixed admissible `u∈[0,(1−γ)⁻¹]`:

- The source absorbing empirical MDP's actual optimal trajectory-value vector is a deterministic function of the entire code of samples at states other than `x`. The code includes every action and sample index at those other states. A concrete completion fills every omitted coordinate with `x`; the proof invokes the already integrated fixed-u optimal-value invariance, rather than assuming factorization.
- Under the actual product sampling law, this code is independent of the **whole ordered N-sample row** `(x,a)`. The proof applies `samplingLaw_independent` and `iIndepFun.indepFun_finset` to explicitly disjoint coordinate blocks, then uses a measurable reindexing. The code is also proved measurable.
- Measurable composition proves the fixed-u actual optimal trajectory-value vector is independent of the full ordered row and of its actual empirical frequency row. It also proves that an arbitrary fixed finite indexed family of admissible u-values yields a **jointly** independent indexed family of optimal value vectors and the empirical row. The empirical frequency row has the discrete measurable structure (`⊤`) used in the existing `BernsteinFamily` code-level theorem; the value-vector and indexed-family targets carry their ordinary product Borel structures.

The result is stronger than separate coordinatewise independence but is local to the selected removed row. It does **not** assert independence from the entire empirical matrix: the auxiliary model uses data from all other states. The parameter map `u : ι → ℝ` is fixed in advance; nothing here asserts independence of a value at a sample-selected parameter or a selected family member. In particular the empirical-optimal parameter `V̂*(x)` may depend on removed samples. Finite-grid construction, unordered-family cardinality/measurability, simultaneous Bernstein events, the selected-net approximation and the source policy-learning theorem are separate work.

The row-sample independence is valid for any natural `N`; positive `N` is required explicitly only where the empirical frequency distribution and empirical MDP are constructed. The fixed-value proof uses actual greedy infinite-trajectory values, not a separate unproved fixed-point proxy.
