## Mathematical correspondence

The source increment is

```text
Z̃_k = A_{k+1:t}(V_k∘V_k − E_{k−1}[V_k∘V_k]),
floor(t/2)+1 ≤ k ≤ t.
```

The draft maps `n` to source `k=n+1`: its centering uses `tdPastSigma T
(k−1)` with `k=n+1`, hence `tdPastSigma T n`; its tail is
`tdErrorPropagate (n+1) t`, which applies the actual deterministic updates
`n+2,…,t`, i.e. source updates `k+1,…,t`. `tdValueBefore ... k` is the actual
`V_k` iterate. The centering term is an actual conditional expectation under
`tdSamplingLaw M π T`, not the nominal transition-row expectation.

There is one source-index/window mismatch to retain visibly: source
`eq:TD-square-martingale` defines the sequence only for `k>t/2`, equivalently
`n+1>t/2` and `n<t`. `tdSquareTerminalIncrement` is nonzero at every `n<t`,
including the earlier updates. Those additional increments are still centered
and adapted by the proved draft statements, so using them as a broader MDS is
mathematically plausible; however, they are not the source's named
`\widetilde Z_k` window. A source-faithful consumer must either restrict to
`n+1>t/2` or zero-pad the draft increment below that cutoff before claiming
exact correspondence. No such restriction is encoded in this file's
definition.

## Filtration and chronology

The draft's `tdPastSigma T n` is generated by actual sample coordinates at
source times `1,…,n`. `TDCausality.lean` proves the stored time-zero sample is
unused and `V_n` is measurable in this prefix. `TDConditionalMoments.lean`
proves the next source-time layer is independent of this prefix and has the
actual policy-transition marginal. Thus for `k=n+1`, the square observation
is measurable at prefix `n+1`, and its conditional mean is taken at prefix
`n`, matching source history through iteration `k−1`.

The tail coefficients are deterministic functions of the model, rates, and
fixed terminal time. The draft uses the propagator's actual row-sum
representation to express each coordinate as a finite deterministic linear
combination of centered-square observations. Pulling these fixed
coefficients through conditional expectation preserves zero conditional
mean. The statement is valid on the actual synchronous product sampling
law; it does not assume independent fresh samples beyond the project's
proved sampling-law infrastructure.

For the source Freedman filtration, `tdSquareTerminalIncrement_priorSigma_le_past`
shows each strictly prior increment is measurable in the actual used prefix
at time `n`. The subsequent tower step therefore gives centering on the
increment-generated natural history. The draft also proves centering on the
full actual prefix filtration, which is the filtration used by the existing
fixed-terminal TD Freedman assembly.

## Boundary and claim limits

When `n≥t`, the draft zero-pads the terminal sequence; this matches a fixed
terminal sum. At active indices, `t≤T` gives `n+1≤T`, so the actual update
coordinate exists. It does not prove an increment magnitude cap, square
conditional-variance bound, sharp energy inequality, or Freedman event.
Those remain separate targets. The draft has no stated dependence on the
source's late-time condition because it proves only centering/adaptedness.

No source lemma closure or production integration is claimed. The source
window mismatch above should be resolved at the consumer/definition boundary
before this draft is used to justify the exact late-window martingale in
`eq:TD-square-martingale`.
