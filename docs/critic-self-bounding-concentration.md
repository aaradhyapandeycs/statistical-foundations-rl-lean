The population variance is the finite row expectation of the squared centered value (`Formalization/Probability/Variance.lean`), and empirical variance applies that same variance to the actual frequency row, with denominator N (`EmpiricalVarianceBernstein.lean`, `EmpiricalRow.lean`). The sample law is the product of N copies of the row law; its coordinate marginal and independence theorems establish the intended iid law. The local discrete measurable space on the finite state carrier induces the finite product space, so every event used is measurable; the union bound uses actual finite probability measure real values. No independence of the two auxiliary events is required.

For the main export the mathematical inputs are a finite state type, a genuine finite probability row d, a fixed vector V, N > 0, B > 0, t > 0, and 0 ≤ V(s) ≤ B for every state. There is no concentration premise. The failure event is strictly `sqrt(empiricalVariance) + t < sqrt(population variance)` and its claimed bound is exactly `3 exp(-N t²/(16 B²))`.

Independent calculation: with σ² = Var(V), Z the empirical variance, W = (V − EV)², a = σt/2, r² = a and u = t/(4 B²σ), the recentering identity Z = empirical mean(W) − (empirical mean(V) − EV)² gives the event inclusion into `{a ≤ σ² − empirical mean(W)} ∪ {r ≤ |empirical mean(V) − EV|}`. This holds with the displayed strict and weak boundary choices. For t ≤ σ, `u B² ≤ 1`; the W lower-tail exponent is exactly −Nt²/(16B²), using Var(W) ≤ B²σ². The second ingredient is **two-sided** Hoeffding, producing `2 exp(−Nσt/B²) ≤ 2 exp(−Nt²/B²)`. Taking a union bound gives the stronger intermediate result and then the advertised factor 3. The proof and imported statements match these calculations.

Endpoint review: N = 1 and deterministic or constant laws are allowed; the estimate may be vacuous. For t = σ the strict failure event is empty, though the nontrivial-branch bound still applies. For t > σ and for σ = 0 with t > 0, the proof explicitly obtains an empty event without dividing by σ. Values 0 and B are allowed. B = 0, N = 0, and t = 0 are outside the exported theorem; the confidence form further assumes 0 < δ < 1, and the exponential-radius form x > 0. No claim is made that those excluded cases were separately formalized. The confidence result bounds failure by δ, hence gives success probability **at least**, not strictly greater than, 1 − δ.
