*Statistical Foundations of Reinforcement Learning: A Non-Asymptotic Perspective*,
[arXiv:2610.41903v1](https://arxiv.org/abs/2610.41903v1), submitted 30 October 2026.

[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

Original article text and figures remain attributed to the six authors.

Run `python3 scripts/fetch_source.py` from the repository root to restore the
original source archive, its extracted tree, and the 326-page PDF. SHA-256 hashes
of both downloads and every extracted file are recorded in `provenance.json`.
The ignored `upstream/` tree is immutable mathematical reference material.

The complete arXiv archive includes publisher formatting files with separate
copyright notices. This repository links to and verifies the archive instead
of republishing those formatting files. Source locators in coverage records
refer to the exact restored tree.
